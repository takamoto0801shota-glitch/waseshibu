# わせしぶ 仕様書

最終更新: 2026年6月  
対象: 動的リズム調整（Desire OS）現行実装

---

## 1. プロダクト定義

**わせしぶ** は、欲望を利用して学力向上を実現する意思決定OSです。

固定ポモドーロではありません。勉強時間と休憩時間は **セッションごとにAIが動的調整** します。

目標は「予定時間の完走」ではなく **「その日の勉強時間を持続的かつ意欲的に消化すること」** です。

---

## 2. モード（開始リズム）

モードは固定サイクルではなく、**最初のリズムの目安** です。

| モード | 開始リズム |
|--------|-----------|
| 軽め | 30分勉強 → 10分自由 |
| 自習 | 45分勉強 → 10分自由 |
| 本気 | 60分勉強 → 10分自由 |
| 学年一位 | 90分勉強 → 10分自由 |

---

## 3. 調子チェック（3択のみ）

各 **勉強セッション終了後** にユーザーが回答:

| 入力 | 意味 | AIの調整 |
|------|------|---------|
| 😀 絶好調 | 集中度高い | 勉強時間延長（+15分程度） |
| 🙂 普通 | 普通 | リズム維持 |
| 😫 きつい | 疲労高い | 勉強時間短縮（-15分程度） |
| 😫 連続きつい | 疲労非常に高い | 短縮 + 自由時間追加（+10分） |

入力負荷は3タップのみ。

---

## 4. セッションフロー

```
勉強セッション
  ↓
😀🙂😫 調子チェック
  ↓
AIが次のリズムを決定
  ↓
自由時間（動的な長さ）
  ↓
次の勉強セッション（科目・時間はAI決定）
  ↓
（今日の目標時間まで繰り返し）
```

余り時間は復習ブロックとして消化。

---

## 5. ロードマップ（`/menu`）

固定プランではなく、**セッション履歴・現在地・残り時間** からリアルタイムに投影するタイムライン。

| 表示 | 意味 |
|------|------|
| ✓ | 完了したステップ |
| ▶ | 今ここ（勉強中・調子チェックなど） |
| □ | これからのステップ |
| 🏁 | ゴール（完了） |

画面上部に **ゴールまであとNステップ** と **次の報酬** を表示。調子チェック後のリズム変更は即座に投影へ反映され、`POST /api/roadmap` でAIが今後のステップを微調整する。

---

## 6. 画面構成

| パス | 内容 |
|------|------|
| `/` | 勉強時間 + モード + やりたいこと |
| `/menu` | ロードマップ（現在地・次のステップ・報酬・ゴールまでの距離） |
| `/session` | 勉強 → 調子チェック → 自由時間 |
| `/complete` | 完了 |

---

## 7. API

- `POST /api/plan` — 今日のプラン初期化（目標時間・開始リズム）
- `POST /api/rhythm` — 調子に応じた次リズムの決定（OpenAI + ルールフォールバック）
- `POST /api/roadmap` — ロードマップの投影とAI微調整（固定プランではなくリアルタイム進化）

---

## 8. データ

- localStorage: `waseshibu-v6`
- `DailyPlan` — 目標時間・動的リズム・セッション履歴・`roadmapSteps`（投影キャッシュ）
