# Google ログイン（Supabase Auth）セットアップ

## 1. Supabase プロジェクト作成

1. [Supabase](https://supabase.com) でプロジェクトを作成
2. **SQL Editor** で `supabase/schema.sql` を実行
3. **Project Settings → API** から URL と `anon` key をコピー

## 2. Google OAuth 設定

### Google Cloud Console

1. [Google Cloud Console](https://console.cloud.google.com/) → APIs & Services → Credentials
2. **OAuth 2.0 Client ID** を作成（Web application）
3. **Authorized redirect URIs** に追加:
   - `https://<your-project-ref>.supabase.co/auth/v1/callback`
4. Client ID / Client Secret をコピー

### Supabase Dashboard

1. **Authentication → Providers → Google** を有効化
2. Client ID / Client Secret を貼り付け
3. **Authentication → URL Configuration** で Site URL を設定:
   - 本番: `https://atlas-production-c8d3.up.railway.app`
   - 開発: `http://localhost:3000`
4. Redirect URLs に **以下をすべて** 追加:
   - `https://atlas-production-c8d3.up.railway.app/auth/callback`
   - `https://atlas-production-c8d3.up.railway.app/**`
   - `http://localhost:3000/auth/callback`

   Site URL も `https://atlas-production-c8d3.up.railway.app` に設定すること。

## 3. 環境変数

**重要:** `eyJ...` や `xxxxx` はプレースホルダーです。**anon key は全文**をコピーしてください（200文字以上）。

Supabase Dashboard → **Project Settings → API** から取得し、Railway Variables に設定:

| 変数名 | 値の例 |
|--------|--------|
| `SUPABASE_URL` | `https://abcdefghijklmnop.supabase.co` |
| `SUPABASE_ANON_KEY` | `eyJhbGci...` または `sb_publishable_...`（**全文**） |

```bash
railway variables set SUPABASE_URL=https://あなたのプロジェクト.supabase.co
railway variables set SUPABASE_ANON_KEY=eyJ（anon keyの全文を貼る）
```

`SUPABASE_*` はサーバー実行時に読むため、**再ビルドなしで反映**されます。
設定後すぐ https://atlas-production-c8d3.up.railway.app/login を開き直してください。

## 5. 動作確認

1. `/login` で「Googleでログイン」
2. Google 認証後 → `/auth/callback` → ホームへ
3. 初回のみオンボーディング → 選択内容が Supabase に保存
4. 再訪問時 → 自動ログイン + 前回の状態を復元
5. マイページ → 「Googleアカウントからログアウト」

## 6. うまくいかないとき

ログイン画面の**赤いエラーメッセージ全文**を確認してください。よくある原因:

| エラー | 対処 |
|--------|------|
| `PKCE code verifier not found` | ブラウザの Cookie を許可、シークレットモードを避ける |
| `redirect_uri_mismatch` | Supabase の Redirect URLs を確認 |
| `Invalid API key` | Railway の `SUPABASE_ANON_KEY` を全文再設定 |
