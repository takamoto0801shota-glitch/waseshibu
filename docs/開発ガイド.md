# わせしぶ 開発ガイド

## 開発フロー（標準）

```
Cursor → GitHub（main push） → Railway（自動デプロイ）
```

**動作確認は Railway 上の URL で行う。** ローカル `npm run dev` はデバッグ用のみ。

## 技術スタック

- Next.js 15 + TypeScript + Tailwind CSS v4
- Zustand（localStorage: `waseshibu-v6`）
- Railway（本番ホスティング）
- OpenAI API（`/api/rhythm`, `/api/roadmap`）

## API 一覧

| エンドポイント | 役割 |
|---------------|------|
| `POST /api/plan` | 今日のプラン初期化 |
| `POST /api/rhythm` | 調子に応じたリズム調整 |
| `POST /api/roadmap` | ロードマップ投影・AI微調整 |

## 日常の作業

```bash
# 1. Cursor で編集
# 2. コミット & push
git add .
git commit -m "説明"
git push origin main

# 3. Railway が自動デプロイ（数分）
# 4. Railway URL で確認
```

## 環境変数

| 変数 | 設定場所 | 説明 |
|------|---------|------|
| `OPENAI_API_KEY` | Railway Variables | AIリズム・ロードマップ調整 |

ローカルで試す場合のみ:

```bash
cp .env.example .env.local
```

## Railway 操作

```bash
railway login
railway status          # プロジェクト状態
railway logs            # ログ確認
railway open            # ダッシュボードを開く
railway domain          # 公開 URL 確認
```

## トラブルシューティング

### Railway デプロイ失敗

```bash
railway logs
```

- `OPENAI_API_KEY` 未設定 → AIなしで動作（ビルドは成功するはず）
- Node バージョン → `package.json` の `engines.node >= 20`

### ローカル開発時の .next 破損

`Cannot find module './611.js'` 等は `.next` キャッシュ破損。

```bash
npm run dev:reset
```

**注意:** `npm run dev` を複数ターミナルで同時起動しない。
