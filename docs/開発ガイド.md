# わせしぶ 開発ガイド

## 開発フロー（標準）

```
Cursor で編集 → git push（バックアップ） → npm run deploy（本番反映）
```

**本番の更新は `npm run deploy` が必要です。** `git push` だけでは Railway は更新されません（GitHub 連携を別途設定していない場合）。

**動作確認は Railway 上の URL で行う。** ローカル `npm run dev` はデバッグ用のみ。

## 技術スタック

- Next.js 15 + TypeScript + Tailwind CSS v4
- Supabase Auth（Google ログイン）+ `user_data` クラウド保存
- Zustand（ランタイム状態、変更は Supabase に自動同期）
- Railway（本番ホスティング）
- OpenAI API（`/api/rhythm`, `/api/roadmap`）

## 日常の作業

```bash
# 1. Cursor で編集
# 2. コミット & push（GitHub バックアップ）
git add .
git commit -m "説明"
git push origin main

# 3. 本番デプロイ（ターミナルから）
npm run deploy

# 4. 状態・ログ確認
npm run deploy:status
npm run deploy:logs

# 5. 本番 URL で確認（ブラウザは Cmd+Shift+R で強制リロード）
npm run deploy:open
```

### 初回だけ（Railway CLI セットアップ）

```bash
npm install -g @railway/cli
railway login
cd /path/to/わせしぶ
railway link    # プロジェクト atlas → サービス atlas
```

### デプロイコマンド一覧

| コマンド | 説明 |
|---------|------|
| `npm run deploy` | ローカルビルド確認 → Railway にアップロード＆ビルド |
| `npm run deploy:quick` | ビルド確認なしで即アップロード |
| `npm run deploy:status` | 直近デプロイの成否を表示 |
| `npm run deploy:logs` | ビルドログ末尾を表示 |
| `npm run deploy:open` | Railway ダッシュボードを開く |

**注意:** `railway redeploy` は古いイメージの再起動だけで、最新コードは反映されません。必ず `npm run deploy` を使ってください。

## トラブルシューティング

### Railway デプロイ失敗

```bash
railway logs
```

- `OPENAI_API_KEY` 未設定 → AIなしで動作（ビルドは成功するはず）
- Node バージョン → `package.json` の `engines.node >= 20`

### ローカル開発時の .next 破損

`Cannot find module './611.js'` 等は `.next` キャッシュ破損。

```bash
npm run dev:reset
```

**注意:** `npm run dev` を複数ターミナルで同時起動しない。
